# Генератор синтетических изображений ГРЗ

Полностью детерминированный генератор (`random seed` → идентичный набор) знаков по ГОСТ Р 50577-2018:

| kind | что рендерится |
|---|---|
| `type1`  | 520×112, белый, `Б ЦЦЦ ББ РР(Р)` |
| `type1a` | 290×170, белый, две строки: `Б ЦЦЦ` / `ББ` + поле региона с RUS и флагом |
| `type1b` | 520×112, жёлтый; 55 % — формат ГОСТ `ББ ЦЦЦ РР(Р)`, 45 % — формат из задания `Б ЦЦЦ ББ РР(Р)` |
| `other`  | прицепы (тип 2), мотоциклы (тип 4), тракторы (тип 3), полиция (тип 20, синий), военные (тип 5, чёрный), дипломатические (типы 9–11, красный), транзитные (тип 15), иностранные (KZ, BY, UA, UZ, KG, AM, GE, EU) |

Пайплайн сцены: рендер знака (шрифт ГОСТ + 3 запасных шрифта, джиттер геометрии) → рамка/болты/грязь/
царапины/окклюдеры (закрытые символы помечаются `#`) → освещение и блики → перспективная проекция
с случайным положением камеры (yaw ±50°, pitch ±30°, roll ±15°) → вклейка в фон с подгонкой яркости →
деградации кадра (ночь, дождь, снег, смаз, расфокус, шум, потеря разрешения, JPEG).

Фоны: реальные фотографии датасета (`--backgrounds images/real --meta meta.csv`) — при этом настоящие
знаки на фото **заменяются** синтетическими по их четырёхугольникам (поэтому на синтетических
изображениях нет неразмеченных знаков), плюс процедурные фоны с текстовым «мусором».

```bash
pip install -r requirements.txt
# полный набор датасета (5000+ сцен), воспроизводится по seed
python generate.py --out .. --n 5200 --seed 42 --backgrounds ../images/real --meta ../meta.csv --procedural-frac 0.25
# только кропы для обучения распознавателя
python generate.py --mode crops --out /tmp/ocr --ocr-crops /tmp/ocr --n 60000 --seed 11
```

Выход: `images/synthetic/*.jpg`, `labels/*.txt` (формат YOLO-pose: `cls cx cy w h x1 y1 x2 y2 x3 y3 x4 y4`,
нормировано; классы 0=type1, 1=type1a, 2=type1b, 3=other), `meta_synthetic.csv` в формате `meta.csv` задания.

Шрифты: `GOST-R-50577-93.ttf` (stanlapru/rus-carplates-font, DWYW-лицензия), Roboto Condensed, Oswald,
PT Sans Narrow (SIL OFL 1.1) — лицензии лежат рядом в `fonts/`.
