# RU-Plates-1A1B — датасет нестандартных ГРЗ (типы 1, 1А, 1Б, прочие)

Датащит датасета, собранного для полуфинала Volga IT 2026 (дисциплина «Искусственный интеллект и анализ данных»).
Лицензия датасета — **CC BY 4.0** (см. `LICENSE`); реальные фотографии сохраняют лицензии источников
(CC0 / Public Domain / CC BY / CC BY-SA, перечислены в `attribution.csv` и в поле `license` файла `meta.csv`).

> **Где лежат изображения.** В git-репозитории хранятся только метаданные (`meta.csv`, `attribution.csv`,
> датащит, отчёт валидатора, генератор). Сами изображения и файлы разметки выложены в разделе
> [Releases](../../releases/latest) двумя архивами: `dataset-real.zip` (2682 реальных фотографии,
> разметка, метаданные) и `dataset-synthetic.zip` (5135 синтетических сцен с разметкой). Синтетическую
> часть можно не скачивать, а пересобрать побайтово той же командой с фиксированным seed — см. раздел
> «Синтетические данные».

## Структура

```
dataset/
  images/real/         реальные фотографии (лица размыты)
  images/synthetic/    синтетические сцены, сгенерированные generator/generate.py (seed фиксирован)
  labels/              по одному .txt на изображение, формат YOLO-pose (см. ниже)
  meta.csv             одна строка на один знак (формат задания, разделитель ;)
  attribution.csv      источник, автор, лицензия каждого реального изображения
  generator/           скрипт генерации синтетики + requirements + шрифты с лицензиями
  README.md, LICENSE
  validation_report.txt отчёт валидатора tools/validate_dataset.py
```

`labels/*.txt`: строка на знак — `cls cx cy w h x1 y1 x2 y2 x3 y3 x4 y4` (нормированные координаты;
классы 0=type1, 1=type1a, 2=type1b, 3=other; углы по часовой стрелке от левого верхнего).

`meta.csv`: `image;plate_num;plate_type;bbox;quad;is_vehicle;is_synthetic;source;license;conditions` —
точно по разделу 6 задания. `plate_num` — латиница в верхнем регистре, `#` для нечитаемых позиций.
Для типа 1Б встречаются два формата номера: `Б ЦЦЦ ББ РР` (формат из задания) и `ББ ЦЦЦ РР`
(формат ГОСТ Р 50577-2018, именно он стоит на большинстве реальных автобусов и такси).

## Источники и методика сбора реальных данных

1. **Wikimedia Commons** (API, скрипт `solution/tools/harvest_commons.py`). Категории и запросы:
   «Buses in Russia by city», «Marshrutka in Russia», «Taxis in Russia», «Yandex.Taxi in Moscow»,
   серии фотографий «Moscow, <марка> … 2024–2026», «Vladivostok/Khabarovsk … 2024», «Automobiles in Moscow /
   Saint Petersburg», «License plates of Kazakhstan / Belarus / Ukraine», «Trailer / Military / Diplomatic
   license plates of Russia», «Motorcycles in Russia» и др. Для каждого файла сохранены страница-источник,
   автор, лицензия и её URL. Оставлены только файлы с лицензиями CC0, Public Domain, CC BY, CC BY-SA.
2. **Openverse API** (агрегатор Flickr CC) — небольшая доля изображений, аналогичная фиксация лицензий.
3. Изображения, на которых человек является смысловым центром кадра, исключены; лица на остальных
   размыты (детектор YuNet, `solution/tools/blur_faces.py`; число размытых лиц указано в `attribution.csv`).
   Поле `conditions` у реальных знаков — **измеренное по изображению**, а не оценочное суждение
   (`solution/tools/estimate_conditions.py`): `night` — медианная яркость кадра, `glare` — доля
   пересвеченных пикселей на выровненном знаке, `motion_blur` — энергия градиента и её направленность,
   `dirt` — низкочастотная вариация яркости поля знака, `angle` — отклонение углов четырёхугольника
   от 90° более чем на 8°. Метки `rain`/`snow` автоматически не выводятся и проставлены только там,
   где их указал ревьюер.
4. Изображения отладочного набора организаторов не использовались.

## Методика разметки

Разметка **полуавтоматическая с ручной проверкой каждого знака**:
1. собственная модель (детектор YOLO11-pose, обученный сначала только на синтетике) предлагает
   четырёхугольник, тип и чтение;
2. каждый кандидат просмотрен человеком на контактном листе (выровненный кроп + контекст):
   текст и тип исправлены вручную, ложные срабатывания отклонены; изображение включено в датасет только
   если все кандидаты на нём проверены;
3. нечитаемые позиции обозначены `#`; `is_vehicle=0` присвоен знакам на самокатах/щитах/витринах.
Заметки ревьюера (`work/review/*/notes`) и итоговые решения (`decisions.csv`) сохранены в рабочем каталоге проекта.

## Контрольный проход разметки

После обучения финального детектора он был прогнан по всем 2682 реальным изображениям, и все его находки,
не пересекающиеся с уже существующей разметкой, были выведены на контактные листы и **просмотрены
человеком**. Так нашлись 224 знака, которые пропустил слабый стартовый детектор и которые поэтому никогда
не попадали на проверку: 180 из них подтверждены и добавлены в разметку (144 `type1`, 14 `type1b`,
6 `type1a`, 16 `other` — белорусские, киргизские, мотоциклетные и дипломатические), 44 отклонены как
нечитаемые или неоднозначные. Это важно не только для полноты датасета: изображение с неразмеченным
знаком учит детектор считать знак фоном.

## Синтетические данные

Генератор `generator/generate.py` (см. `generator/README.md`): рендер знаков по геометрии ГОСТ
(12 подтипов, включая прицепы, мотоциклы, полицию, военные, дипломатические, транзитные и иностранные),
рамки/болты/грязь/окклюдеры (закрытые символы помечаются `#`), случайная 3-D поза, вклейка в реальные
фотографии датасета **с заменой настоящих знаков по их четырёхугольникам**, деградации камеры
(ночь, дождь, снег, смаз, расфокус, шум, JPEG). Команда воспроизведения:

```bash
cd generator && pip install -r requirements.txt
python generate.py --out .. --n 5200 --seed 42 --backgrounds ../images/real --meta ../meta.csv --procedural-frac 0.25
```

## Известные ограничения

- Квадратные знаки (1А) в открытых фотобанках редки: собрано 80 реальных изображений / 57 уникальных
  номеров при рекомендованных 150 / 50 — по уникальным номерам норма выполнена, по числу изображений нет.
  Компенсация: 2343 синтетических изображения с квадратными знаками, вклеенными на место настоящих
  на реальных фотографиях (см. раздел «Синтетические данные»).
- Съёмка в основном дневная и с рук/со штатива; ночных и «камерных» кадров меньше — это компенсируется
  синтетикой.
- Разметка углов знака выполнена моделью и проверена визуально по выровненному кропу; точность углов
  ±2–3 % от размера знака.
